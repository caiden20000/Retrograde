How do we track mission progress?
Whenever something happens, it gets sent to an event bus
The mission manager subscribes to the event bus
When a mission fulfilling event happens, the mission manager 
notices and applies state changes to the mission progress values.

"Something happening" is a change in state.
We can make every change in state fire an event to the event bus.
If we make the redux slices very granular then we could listen for anything.
However, instead of giving specific context within the event,
we'd only be able to give the value change and the entire /old/ state.
